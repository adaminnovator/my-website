TarGraph FMS Driver ID Recognition for EU Standard Trucks

Summary

The content details the process for recognizing driver IDs on TarGraph systems integrated with FMS (Fleet Management System) devices installed on European trucks that comply with EU standards. The explanation covers preconditions, platform setup, device compatibility, configuration steps, data verification, and hardware connection specifics.

Preconditions and Vehicle Requirements

  • The system applies only to European trucks over 3.5 tons equipped with EU-standard TarGraph devices.
  • The truck must have an FMS-enabled system installed and activated.
  • Activation of FMS may depend on the vehicle supplier or dealer; some dealers charge to enable it at the point of sale.
  • Both the TarGraph device and FMS system must be active for the driver ID recognition process to function properly.

Platform Configuration

  • The platform requires tenant users to enable the FTC (Function Package) for CAN ID recognition.
  • The driver recognition method must be set to dynamic recognition using FMSCAN driver ID.
  • When adding a driver on the platform, the driver card number must exactly match the TarGraph ID card number read from the device.
  • The driver card ID format generally includes:
    • A country code prefix
    • A space or multiple spaces
    • Followed by a string of digits
  • The platform verifies the driver ID by matching it with the ID read from the vehicle’s device.

Device Compatibility and Setup

  • Supported devices must have software version 2.4.5 or higher, including:
    • C6 Lite 2.0
    • AD Plus
    • M1 2.0
  • In the device settings, under "collection," select FMS protocol.
  • The baud rate should correspond to the truck’s CAN bus speed, usually 250 kbps but can vary.
  • The data upload interval defaults to 300 seconds but can be adjusted (customers typically set it around 60 seconds, with a minimum of 15 seconds).

Data Verification and Logs

  • After configuration, the operation log on the device interface will show the detected driver card number if reading is successful.
  • Successful display of the driver card number confirms the device is correctly receiving FMS data.
  • The FMS connection can be verified using default flashing tools or customized FMS cables.

Hardware Connection Details

  • FMS connectors use a standard green 12-pin connector.
  • If a vehicle has the FMS connector, it is generally compatible across different devices.
  • There is a distinction between cables for HFG with C220 chips and AD Plus devices:
    • Both cables appear similar but have different chip definitions.
    • Labels help differentiate: cables marked C220 vs. those without labels for AD Plus220.
  • A critical installation detail involves a small resistor in the FMS line:
    • Depending on the vehicle, the resistor may need to be cut or kept.
    • This depends on whether the vehicle and devices already have termination resistors.
    • Installers must measure the resistance on both ends of the CAN bus to decide on resistor removal or retention.

Key Insights

  • Strict matching of driver card IDs between TarGraph and platform is essential for accurate driver recognition.
  • The software and hardware compatibility of devices and vehicles is crucial for system success.
  • Physical connection nuances, especially regarding resistors and cable types, significantly affect FMS data collection.
  • The system primarily supports European trucks over 3.5 tons with EU-standard TarGraph and active FMS.
  • The platform and device configurations must be carefully coordinated to ensure driver IDs are dynamically and correctly recognized.
