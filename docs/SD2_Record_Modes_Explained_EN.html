SD Card 2 Recording Modes Explained

[SDRecord Mode] defines the role of the secondary SD card (SD Card 2). The primary card (SD Card 1) continuously records the main stream by default, while this mode determines what the secondary card stores and when it stores it. Depending on the selection, SD Card 2 acts as a redundant backup, event-protected storage, capacity extension, or a separate sub-stream drive.

4 modes: Sub-Record · Mirror Record · Alarm Backup · Loop-Record

Key Concepts Main Stream / Sub Stream / Dual SD Cards

Before comparing the four modes, get familiar with three basic objects:

M

Main Stream

The high-resolution, high-frame-rate evidence-grade video stream. High bitrate and heavy storage consumption — the core data for post-incident review.

S

Sub Stream

A lower-resolution stream compressed from the same video source, used for remote live preview. Low bitrate with minimal storage pressure.

1

SD Card 1 · Primary Card

The primary storage card. Continuously records the main stream by default and overwrites the oldest files when full (loop recording).

2

SD Card 2 · Secondary Card

The second storage card. Its behavior is defined entirely by [SDRecord Mode] — which is exactly what the four modes below differ in.
